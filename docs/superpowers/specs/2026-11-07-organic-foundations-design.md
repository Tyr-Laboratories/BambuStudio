# Branched foundations for organic supports

Organic supports rooted on removable model contacts need several separated feet to resist falling over during printing. For trees that both start and end on the model, generate the lower half with the existing organic generator in reversed Z, converging upward from foundation contacts. Retain the existing upper branching topology and model contacts; a degree-two stem crossing the midpoint may be straightened between its surviving junctions. Trees rooted on the build plate retain their existing generation and geometry.

The user requested reuse of the existing branching algorithm and settings, with a midpoint split along Z. No new process setting is introduced. Existing branch angle, diameter, tip diameter, branching distance and growth rules drive both halves. Model contact separation and bottom interface settings retain their physical meanings.

## Implementation decisions

Classify connected trees after normal path generation and smoothing. A tree must have an actual model landing above the raft/build plate to qualify. Its midpoint is the printable layer nearest the halfway Z between its foundation and highest supported tip. A midpoint crossing more than one connected physical stem requires multiple foundation feet for each resulting connected branch component. Overlapping graph seam nodes may contribute to the same physical stem; an empty or single-foot per-node contribution does not by itself reject the combined foundation.

Keep the two directed forests separate: the existing graph allows multiple branches above a stem but only one stem below a junction. Inverting graph links would violate that invariant. Reuse its generator on a reversed collision-volume view and combine the resulting geometry per tree instead.

Foundation candidates are existing permitted model contact regions near the original landing, restricted by the reverse generator's reachability from the midpoint. Sampled feet prefer the nearest eligible seam stem sharing that landing height, preventing overlapping copies of a platform's foundations. If this allocation removes every sampled route to a required weld, retain its nearest original sample with its original layer and state. The ordinary solver and final physical-component checks still determine whether it is usable; a shared physical foot is counted once. The reversed view maps collision queries to the real physical layer, preserving asymmetric contact gaps and XY clearances. Its avoidance cache is calculated in reversed order, starting at a midpoint landing constrained by the original stem position and radius. Radius requests above that endpoint limit are unreachable; the existing growth solver chooses its normal no-growth fallback. Apply this physical-radius constraint before cache quantization so radii on opposite sides of the limit cannot alias in a coarse collision-radius bucket. It does not allow routes to terminate on intervening surfaces. Support blockers also constrain the new foundations.

Use one shared contact-preparation and sampling function for both directions, followed by the existing propagation/merge, point selection, smoothing and tube extrusion functions. Feed it raw permitted contact masks; the additional painted-boundary exclusion uses the actual tip radius, never the minimum grown-trunk radius. Preserve the original branching settings and shared interface-dependent sampling. Limit its virtual roof depth to the smaller of the top-interface count and the resolved physical bottom-interface count: a reflected dense band must not become hollow base beneath its sampled tips. With bottom interfaces disabled, the same sampler generates direct model-contact tips. Reflect all interface geometry produced by that generator with the branches; distinguish model-touch contact masks from branch tips supported by that interface. The normal physical renderer assigns bottom-interface roles and counts, including Same as top (-1). Publish Organic model-contact masks only when both top and bottom interfaces are enabled by that renderer, including original supports retained as a fallback. With top interfaces disabled, retain those masks for grounding validation but leave the printed feet as ordinary organic support; otherwise projecting the masks creates sparse interface rows above an ordinary base contact. Disable virtual build-plate foot widening because the midpoint is a join, not a plate contact. Pin each feasible seam position during the initial reversed smoothing. Reflect the generated tube mesh back into physical Z. Retain the native reflected slice at the midpoint: its sample plane is half a layer below the weld Z and belongs to the new lower forest. Initially retain original upper slices from the next layer onward. If their printed sheaths need a transition, start it against that first retained upper slice and bound successive lower collar sections by the existing per-layer branch movement and radius-growth envelope. Never overwrite the reflected seam with the discarded original lower slice. Use the existing contour regularization for both collar construction and sheath validation. Back off a collar step when its maximum permitted expansion joins nearby tubes too quickly to support their inner walls; retain the same support predicate and never exceed the configured movement/growth budget. Recheck actual sheath support and physical collisions; never modify a contact tip to make the collar fit. Trace branch-only connectivity independently of interface bands before and after collar edits, so an interface cannot make a severed stem count as a second foundation. Preserve bottom contact generation and run the existing per-tree geometry cleanup on the combined result. Bottom interfaces have an independent direction counter so adding model feet cannot rotate distant build-plate top interfaces.

After both forests exist, the midpoint is not itself a physical junction. A removed lower merge can leave an upper stem aimed at its old midpoint position, creating a needless dogleg. For an unbranched span crossing the midpoint, identify the nearest surviving junction or contact in each direction. Keep their positions, all contact tips, topology, radii and layer heights fixed. Replace only interior XY positions with the endpoint chord when the entire radius-aware path clears the model and respects per-layer branch movement. Reuse the existing tube extrusion for the changed paths. Rebuild affected layer ranges from all branch contributions, including the full junction-cap spans, so sibling overlap is preserved. Validate both endpoint joins, the midpoint, grounding and separated feet before applying upper and lower changes together. Try all eligible chords together first. If that aggregate fails validation, start with the valid original foundation and test each chord against the last accepted aggregate. Every trial runs the same complete validation. For extended span checks, an unchanged normalized shell component is exempt only when both its direct overlap with the layer below and its coverage within the permitted growth envelope also match the original; every changed relationship must satisfy the original strict predicate. This prevents untouched legacy geometry from vetoing a safe shortcut without weakening checks on changed material. An unsafe sibling retains its original path without blocking an independent safe shortcut. Commit only the final valid aggregate, then derive slope-dependent cooling from the accepted axes and reflected branches so removed paths cannot leave stale cooling masks. A blocked chord or a real junction at the seam retains that stem’s original path. Build-plate forests never enter this correction.

Only replace the original lower half and its optional unbranched midpoint span after all required foundation branches and their connections are valid. Short cavities, narrow/obstructed contact surfaces, or restrictive branch-angle limits may not admit separated feet and a valid join; retain the original support when a valid replacement cannot be generated. This fallback must be visible in test coverage, not treated as successful branching.

## Verification

- A synthetic model-to-model cavity must produce separated foundation feet, converge near the midpoint, and retain upper branching and roof coverage. An equal-width thin-ledge fixture using a 49 mm gap and 35-degree branches must retain substantial lower branching and footprint span; a broad platform alone does not cover contact-mask erosion or midpoint-radius mismatches.
- Adjacent extrusion footprints through the seam must overlap; the shoulder check allows normal contour-processing tolerance. Bottom gap and interfaces must remain correct, including Same as top (-1), disabled bottom interfaces, and bottom counts smaller than the top count. Check actual adjacent extrusion footprints at the contact-to-branch transition.
- With top interfaces disabled, both accepted foundation feet and original fallback support toolpaths and roles must match the bottom-zero case; enabled interfaces must still start at the contact.
- A clear bowed degree-two span must become its endpoint chord without moving junctions, contacts or changing radii. A chord blocked by the model must retain the valid detour atomically. Verify the actual printed stem loses its midpoint direction reversal.
- A distant build-plate tree must retain its generated geometry, including its plate foot.
- Reverse-volume tests cover direction, constrained seam position and radius (including requests sharing a cache bucket), blockers, unequal top/bottom gaps, and cancellation during lazy calculation.
- Existing support-base painting, routing, raft and slicing tests continue to pass.
- Source tests and slicing establish software behavior. Physical print stability requires a later print trial.
